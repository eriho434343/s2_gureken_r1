# 昇進試験 学習アプリ

社内昇進試験に向けた個人学習ツールです。完全無料・完全ブラウザ完結で動作します。

## 機能

- **SM-2間隔反復**: Anki採用の実証済みアルゴリズムで、忘れそうなタイミングに自動再出題
- **穴埋め式問題**: `【①】【②】` の記法で空欄を作成し、視覚的に強調表示
- **アクティブリコール**: 問題 → 「答えを見る」 → 自己採点(もう一度/難しい/普通/簡単)
- **インターリービング**: 複数カテゴリを混ぜて出題
- **3カテゴリ**: カテゴリは自由に使い分け可能
- **問題追加・編集**: ブラウザ上で直接作成・編集
- **複数人での共有**: 問題のみエクスポート → 渡す → 相手がインポート。学習履歴は各自で独立管理
- **CSV/TSV取込**: ExcelやWordから書き出した問題を一括取込
- **音声読み上げ**: 通勤中・移動中にイヤホンで聞ける
- **進捗統計**: 30日ヒートマップ・カテゴリ別習得進捗・試験日までの推定ペース
- **完全オフライン対応**: 一度ブラウザで開けばネットがなくても動作 (ブラウザキャッシュ利用)
- **ダークモード**: 端末設定に連動
- **ローカル出典表示**: 1問の全穴を回答した後、CSV出典・資料名・PDFページ・本文抜粋を解答下に表示
- **該当ページ画像**: 文字の出典より上にPDFページのスクリーンショットを表示し、タップで全体表示・等倍表示を切替
- **二重ハイライト**: 特定できた解答箇所を、PDFページ画像の黄色枠と原文テキストのマーカーの両方で表示

## ⚠ 社外秘情報の扱い

このアプリは **「コードは公開・データは端末内のみ」** の設計です。

### 安全な使い方

| 種類 | 置き場所 | 備考 |
|---|---|---|
| アプリのソースコード | GitHub (公開) | 学習ロジックのみ。機密情報は含まない |
| 公開資料由来のシード問題 | GitHub (公開) | 公開情報から作成した問題のみ |
| 社内資料・過去問由来の問題 | **端末内のみ** | GitHubには絶対に置かない |
| 学習進捗・履歴 | **端末内のみ** | GitHubには送信されない |
| ローカル出典パック (`source-pack.local.json`) | **端末内のみ** | 資料本文・PDFページ画像を含むためGitHubへ絶対に置かない |

社内資料をもとに作成した問題は、**アプリ内の「問題追加」機能** または **CSV同期** で取り込んでください。ローカル出典パックも、設定画面から明示的に選んだ端末の `IndexedDB` にのみ保存され、GitHubには一切送信されません。本文索引はメタデータ領域、ページ画像はBlob専用領域へ分離して保存され、通常バックアップとiCloud同期にも含まれません。

> **重要:** `source-pack.local.json` には元資料の本文抜粋とPDFページ画像が含まれます。アプリ本体のZIPとは分けて保管し、GitHub・GitHub Pages・外部サーバーへアップロードしないでください。

ネットワーク通信はアプリの初回ロード時のみです。問題内容・進捗・操作履歴は外部に送信されません(分析・トラッキングなし)。

### さらに慎重にしたい場合

- `data/seed.json` の中身を `{"version":2,"questions":[]}` に置き換えてからGitHubに上げる(問題を全て手入力・インポートする運用)
- GitHubリポジトリをPrivate化する(GitHub Pro が必要)

## セットアップ

### 1. GitHubでリポジトリを作成

1. https://github.com でアカウント作成(まだの場合)
2. 「New repository」 → 任意の名前 → 「Public」 → 「Create repository」

### 2. ファイルをアップロード

リポジトリページの「uploading an existing file」から以下を全てドラッグ&ドロップ:

```
study-app/
├── index.html
├── app.js
├── styles.css
├── sw.js
├── icon-192.png
├── icon-512.png
└── data/
    └── seed.json
```

「Commit changes」をクリック。`.gitignore` も必ず含めてください。ローカル出典索引・問題CSV・元資料ZIPはアップロード対象外です。

### 3. GitHub Pagesを有効化

1. リポジトリの「Settings」 → 左メニュー「Pages」
2. Source: 「Deploy from a branch」 / Branch: `main` / `/ (root)`
3. 「Save」

1〜2分後に `https://[ユーザー名].github.io/[リポジトリ名]/` でアクセスできます。

### 4. ブックマーク登録

Safariのブックマークやホーム画面の「Webクリップ」に追加すると手軽に開けます。

### 5. 問題CSVとローカル出典データを端末へ読み込む

1. 設定 → **問題の管理** → **CSVから同期する** で `questions-2026-07-10.csv` を読み込む
2. 設定 → **ローカル出典データ** → **出典データを読み込む** で `source-pack.local.json` を選ぶ
3. 設定欄に「照合 443/443問・ページ画像 367問(196枚)」と表示されれば設定完了

出典パックは選択したブラウザのIndexedDBにだけ保存されます。別ブラウザ・別端末では、それぞれ一度ずつ読み込んでください。

## 使い方

### 学習する

ホーム画面でカテゴリとセッション長を選んでボタンをタップ:

- **復習を開始**: 期日が来た問題のみ。毎日まずこれ
- **新規を学ぶ**: まだ見たことのない問題
- **混合学習**: 復習＋新規をシャッフル
- **間違えた問題**: 直近で「もう一度」にした問題

問題が表示されたら頭の中で答えを思い浮かべ、「答えを見る」→ 自己採点:

| ボタン | 意味 | 次回出現 |
|---|---|---|
| もう一度 | 思い出せなかった | 1日後(セッション内で再出題) |
| 難しい | 苦労して思い出せた | 短め |
| 普通 | 普通に思い出せた | 中 |
| 簡単 | 楽勝 | 長め |

1問に複数の穴がある場合、最後の穴で「結果を見る」を押した後にだけ、解答の下へローカル出典が表示されます。回答途中には本文抜粋を表示しません。

**学習スタイル(ホームで選択)**:
- **学習(見るだけ)**: 問題→「答えを見る」→自分で4段階評価(従来通り)
- **解答(入力)**: 各穴に答えを入力して自動正誤判定。複数穴は1個ずつ順番に判定。全穴終了後、**誤答数と解答時間からSM-2評価を自動決定**(全問正解で速い→簡単、全問正解→普通、一部誤り→難しい、半分以上誤り→もう一度)。「次へ」で自動評価を記録。「評価を手動で選ぶ」で上書きも可能。

### 問題の管理はCSVで行う(基本)

問題の追加・編集・削除は、PCのExcel等でCSVを編集して行います。アプリ上では基本的に編集しません。

**基本フロー**:
1. PCのこのアプリで **設定 → 問題の管理(CSV) → ① CSVをエクスポート(id付き)** を押し、現在の問題をCSVで取得(初回でまだ問題が無ければスキップ可)
2. そのCSVをExcel等で開き、行の追加・編集・削除を行う
3. **設定 → ② CSVから同期する** で編集後のCSVを取り込む
4. 確認画面に「新規追加◯件 / 履歴リセット◯件 / 削除◯件」が出るので確認して実行

**CSVの列**:

| 列 | 必須/任意 | 説明 |
|---|---|---|
| `Q&A` | 必須 | 問題と解答を一体化した本文。空欄にしたい語を `【】` で囲む。**囲んだ中身がそのまま解答**になる。例: `【業績】や【事業活動】を【コンプライアンス】に優先させない` |
| `id` | 任意 | 問題の追跡用ID。アプリのエクスポートで自動付与。**編集時は残すこと**(消すと新規問題扱い) |
| `category` | 任意 | `common` / `solution` / `engineering`(日本語表記も可)。省略時は common |
| `tags` | 任意 | セミコロンかカンマ区切り |
| `source` | 任意 | 出典 |
| `year` | 任意 | 対象年度 |
| `importance` | 任意 | 1〜5。空欄は3 |
| `author` | 任意 | 作成者名 |

`Q&A` 列の書き方:

```
Q&A
【業績】や【事業活動】を【コンプライアンス】に優先させてはならない
基準価格は【10.82】円
```

- `【...】` で囲んだ語が空欄になり、囲んだ中身が解答になります
- 穴が複数あれば、出題時に自動で ①②③… と振られます
- 穴が1個でも複数でもOK
- 最小構成は `Q&A` 列だけでも動きます(カテゴリ等は省略可)
- 旧形式(`question`/`answer` の2列)も引き続き読み込めます

**同期の挙動(学習履歴の扱い)**:

| CSVでの操作 | アプリでの結果 | 学習履歴 |
|---|---|---|
| 行の `question`/`answer` を変更 | 内容更新 | **リセット(新規問題扱い)** |
| 行の `tags`/`importance` 等だけ変更 | メタ更新 | **保持** |
| 新しい行を追加(id空欄) | 新規問題が増える | まっさら |
| 行を削除 | アプリからも削除 | 痕跡は残り、復活で再開可能 |
| 変更なし | そのまま | 保持 |

問題文と解答の内容ハッシュで「内容が変わったか」を判定します。`id` 列が無い/空欄の行は、問題文が一致する既存問題に自動で紐付けて履歴を維持します(問題文を変えた場合は新規問題になります)。

**重要**: CSVインポートは「CSVの内容にアプリを完全一致させる」動作です。アプリにあってCSVに無い問題は削除されます。常に**全問題を含むCSV**を取り込んでください(部分的なCSVを入れると他が消えます)。

**社外秘の注意**: CSVには社外秘を含みうる問題が入ります。AirDropや社内ファイル共有など端末間の直接転送を使い、外部サービス経由を避けてください。

### ローカル出典データ

ローカル専用の `source-pack.local.json` には、従来の本文抜粋索引に加えて、出典として実際に使うPDFページのスクリーンショットとハイライト座標が入っています。元PDFをブラウザで毎回解析・描画しないため、回答後の表示は高速です。

- 問題の `id` を優先し、IDがない行は問題文＋解答の内容ハッシュで照合
- 全443問のCSV出典を回答後に表示
- 364問は資料本文の抜粋付き、354問は原文テキストのマーカー付き
- 196枚のページ画像を問題間で共有し、367問で該当ページ画像を表示
- 331問はPDF上の解答位置を座標で特定し、ページ画像にも黄色の枠を重ねて表示
- 画像上の位置を安全に特定できない場合も、誤った枠は出さず、ページ画像と原文マーカーを表示
- 14問は安全に本文一致を特定できなかったため資料名・ページ情報のみ
- エンジニアリング48問は今回の元資料ZIPに含まれないため、CSV記載の出典のみ
- 画面の `PDF p.N` はPDFファイル上の物理ページ番号。資料内の印刷ページ番号とは表紙・目次分ずれる場合あり

ページ画像はWebPへ軽量化し、同じPDFページを複数問題が参照しても端末には1枚だけ保存します。学習中は現在表示しているページだけをIndexedDBから読み込み、画像URLのメモリキャッシュも少数に制限しています。

旧 `source-index.local.json` も引き続き読み込めますが、その場合は従来どおり文字の出典のみです。ページ画像を表示するには `source-pack.local.json` を読み込んでください。

出典データは設定画面から削除できます。削除しても問題・学習履歴は残ります。全データ削除を実行した場合は、本文索引とページ画像の両方が削除されます。

**GitHubへ置いてよいもの:** `index.html`, `app.js`, `styles.css`, アイコン、README、`.gitignore` などのアプリ本体。

**GitHubへ置いてはいけないもの:** `source-pack.local.json`, `source-index.local.json`, `questions-*.csv`, `共通*.zip`, `ソリューション*.zip`, 元PDF、ページ画像、ローカル生成ツール一式。

### 複数人で同じ問題集を使う

代表者がCSVを管理し、各メンバーがそのCSVを「CSVから同期する」で取り込みます。学習履歴は端末ごとに独立するため、誰がどれだけ進めても他の人には影響しません。

### 試験日とペース管理

**設定 → 試験日** を入力すると「試験まで N 日」が表示されます。  
**統計**タブで現在の習得進捗と、必要な1日あたりの消化量を確認できます。

## トラブルシューティング

**Q: アップデート後に画面が古いままになる**  
A: ブラウザのキャッシュをクリアして再読み込みしてください。

**Q: 問題が消えた**  
A: 設定 → 「シード問題を再読込(マージ)」で初期問題のみ復元できます。ご自身で追加した問題が消えた場合、以前にエクスポートしたJSONから復元してください。

**Q: 出典が解答下に出ない**  
A: 設定 → ローカル出典データの状態を確認してください。「未読み込み」なら `source-pack.local.json` を読み込みます。問題文・解答を編集した問題は内容ハッシュが変わるため、出典パックの再作成が必要です。

**Q: 出典は出るがページ画像がない**  
A: 旧 `source-index.local.json` を読み込んでいる場合は文字だけが表示されます。設定から `source-pack.local.json` を読み込み直してください。元資料側でページを特定できない問題には画像を表示しません。

**Q: 出典は出るが本文抜粋がない**  
A: 誤った箇所を表示しないため、本文一致の確度が低い問題はCSV出典または資料名だけを表示します。元資料を直接確認してください。

**Q: 全てリセットしたい**  
A: 設定 → 「全データを削除」。ローカル出典索引も削除されます。

## プライバシー

- 問題・進捗・設定・ローカル出典パックは全てこの端末の `IndexedDB` にのみ保存されます
- PDFページ画像はBlobとして本文索引と分離保存され、表示中のページだけを読み込みます
- ローカル出典パックは通常バックアップとiCloud同期から意図的に除外されています
- 外部サーバーへの送信は一切ありません
- アプリ起動後は完全オフラインで動作します
- 分析・トラッキングなし
- 入力フォームは `autocomplete="off"` でブラウザ自動保存無効化

## 端末間の同期について（重要）

このアプリはサーバーを持たず、データは各端末の中（IndexedDB）にだけ保存されます。

- **問題データベースは自動同期されません。** PCとスマホは独立しています。CSVを書き出して相手に取り込む（「CSVから同期する」）ことで手動で揃えます。`id`列で問題を対応づけます。
- **学習履歴は勉強する端末（スマホ）の中だけ**にあり、CSVには含まれません。CSV経由では移動しません。
- 頻繁に両方で編集する場合は、**編集したらすぐCSVを書き出して、それを次の正本にする**運用にしてください（PC編集→スマホ取込／スマホ編集→CSV書き出し→PCで使用）。古いCSVを取り込むと新しい編集が上書きされます。

### 学習履歴は「穴の解答の中身」にひも付く

進捗は穴ごとに、しかも**穴の中の解答内容**で記録されます。そのため編集しても履歴は最大限保持されます：

| 編集 | 学習履歴 |
|---|---|
| 穴の位置を動かす | 保持（中身が同じなら追従） |
| 問題文（穴以外）を直す | 保持 |
| 穴を追加 | 追加分だけ新規、他は保持 |
| 穴を削除 | 削除分だけ消える、他は保持 |
| 穴の中の解答を変更 | その穴だけ新規、他は保持 |
