# 昇進試験 学習アプリ

社内昇進試験に向けた個人学習ツールです。完全無料・完全ブラウザ完結で動作します。

## 機能

- **SM-2間隔反復**: Anki採用の実証済みアルゴリズムで、忘れそうなタイミングに自動再出題
- **穴埋め式問題**: `【①】【②】` の記法で空欄を作成し、視覚的に強調表示
- **アクティブリコール**: 問題 → 「答えを見る」 → 自己採点(もう一度/難しい/普通/簡単)
- **インターリービング**: 複数カテゴリを混ぜて出題
- **3カテゴリ**: カテゴリは自由に使い分け可能
- **問題追加・編集**: ブラウザ上で直接作成・編集
- **複数人での共有**: 問題のみエクスポート → 渡す → 相手がインポート。学習履歴は各自で独立管理
- **CSV/TSV取込**: ExcelやWordから書き出した問題を一括取込
- **音声読み上げ**: 通勤中・移動中にイヤホンで聞ける
- **進捗統計**: 1日で勉強した問題数・穴あき正解率の30日推移、穴回答ヒートマップ、カテゴリ別習得進捗、試験日までの推定ペース
- **完全オフライン対応**: 一度ブラウザで開けばネットがなくても動作 (ブラウザキャッシュ利用)
- **ダークモード**: 端末設定に連動
- **ローカル出典表示**: 1問の全穴を回答した後、該当PDFページ画像を文字の出典情報より上に表示
- **PDF内ハイライト**: 特定できた穴抜き解答箇所を、ページ画像上の黄色い枠で表示。原文の文字抜粋・文字マーカーは表示しない
- **画像拡大**: ページ画像をタップして全体表示・等倍表示を切替
- **3回正解で定着**: 各穴は累計3回正解するまでSM-2の期日に沿って再出題し、習得後は次回以降の問題文へ正解を埋め込み。「新規を学ぶ」は完全な未学習問題だけを出題
- **穴・問題の周回表示**: 入力中の穴が何周目かに加え、問題全体が何周目かも学習画面に表示
- **忘却リスク優先**: 期限超過が大きい問題、直前に誤答した問題を優先。その後に完了回数が少ない問題を優先し、完全同点はランダム。回答途中で中断した回は未出題扱い
- **出題中編集後のスキップ**: 学習画面から問題を編集・保存した場合、その問題を現在のセッションから除外し、編集後24時間は新しいセッションでも出題しない
- **安全なEnter操作**: 出典画像の拡大中は背後の判定・次へを動かさず、10問・20問完了後はEnterで同じモードを継続

## ⚠ 社外秘情報の扱い

このアプリは **「コードは公開・データは端末内のみ」** の設計です。

### 安全な使い方

| 種類 | 置き場所 | 備考 |
|---|---|---|
| アプリのソースコード | GitHub (公開) | 学習ロジックのみ。機密情報は含まない |
| 公開資料由来のシード問題 | GitHub (公開) | 公開情報から作成した問題のみ |
| 社内資料・過去問由来の問題 | **端末内のみ** | GitHubには絶対に置かない |
| 学習進捗・履歴 | **端末内のみ** | GitHubには送信されない |
| ローカル出典パック (`source-pack.local.json`) | **端末内のみ** | PDFページ画像・ハイライト座標・出典情報を含むためGitHubへ絶対に置かない |

社内資料をもとに作成した問題は、**アプリ内の「問題追加」機能** または **CSV同期** で取り込んでください。ローカル出典パックも、設定画面から明示的に選んだ端末の `IndexedDB` にのみ保存され、GitHubには一切送信されません。出典メタデータはメタデータ領域、ページ画像はBlob専用領域へ分離して保存され、通常バックアップとiCloud同期にも含まれません。

> **重要:** `source-pack.local.json` には元資料のPDFページ画像とハイライト座標が含まれます。アプリ本体のZIPとは分けて保管し、GitHub・GitHub Pages・外部サーバーへアップロードしないでください。

ネットワーク通信はアプリの初回ロード時のみです。問題内容・進捗・操作履歴は外部に送信されません(分析・トラッキングなし)。

### さらに慎重にしたい場合

- `data/seed.json` の中身を `{"version":2,"questions":[]}` に置き換えてからGitHubに上げる(問題を全て手入力・インポートする運用)
- GitHubリポジトリをPrivate化する(GitHub Pro が必要)

## 使い方

### 学習する

ホーム画面でカテゴリとセッション長を選んでボタンをタップ:

- **今日の学習**: 期限到来・期限超過の復習を最優先。セッションに空きがある場合だけ、日次上限内の未学習問題を補充します。誤答問題は翌日へ短縮され、復習候補は推定保持率が低い順に自動選択されます。
- **新規を学ぶ**: 問題内の全穴に学習履歴がない未学習問題のみ。定着中、誤答済み、一部学習済みの問題は出題しません。

従来の「復習を開始」「混合学習」「間違えた問題」は対象が大きく重複していたため、「今日の学習」へ統合しました。復習は、各穴の経過日数と直前に設定された間隔から推定した保持率が低い問題から選びます。同程度なら、直前誤答、失敗回数、古い期日、少ない完了回数の順で優先し、完全同点だけランダムです。回答途中で中断した回はカウントしません。

問題が表示されたら、穴ごとに解答を入力します。正誤と解答時間から次回期日を自動設定します。

| 判定 | 次回期日の基本 |
|---|---|
| 不正解 | 翌日 |
| 誤答直後の次の正解 | 翌日（定着確認をもう1回） |
| 1回目の正解 | 翌日 |
| 2回目の正解・難しい | 3日後 |
| 2回目の正解・普通 | 4日後 |
| 2回目の正解・速い | 7日後 |

3回目の正解でその穴を習得扱いにし、以後は問題文へ正解を埋め込みます。既存履歴の期日はそのまま保持し、更新後の回答から新しい間隔を適用します。

1問に複数の穴がある場合、最後の穴で「結果を見る」を押した後にだけ、解答の下へローカル出典が表示されます。回答途中にはページ画像も文字の出典情報も表示しません。

### 穴ごとの3回正解ルール

- 各穴は、解答速度に関係なく**累計3回正解**すると習得になります。
- 1回または2回正解した穴は「定着中」ですが、期日前には先取りしません。SM-2の期日が来た時だけ「今日の学習」へ含まれます。「新規を学ぶ」には含まれません。
- 問題が出題されたときは、3回正解前の穴をすべて回答します。前回正解した穴も省略されません。
- 3回正解済みの穴は入力対象から外れ、同じ問題の別の穴が出題される際は**問題文に正解を埋め込んだ状態**で表示されます。
- 旧版の学習履歴は保持され、既存の正解履歴から正解回数を自動復元します。旧版ですでに習得済みの穴もそのまま習得済みとして扱います。

### 穴と問題の周回数

- 入力欄には `この穴 N周目` を表示します。
- 問題上部には `問題 N周目` を表示します。
- その回で回答対象になっているすべての穴を判定し、最後に「結果を見る」まで完了した時点で、その問題の周回を1回だけ加算します。複数穴でも1問につき1回です。
- 回答途中でホームへ戻る、再読み込みする、ブラウザを閉じるなどして中断した場合は、問題周回を加算しません。次回も同じ問題周回として表示します。
- 中断した回では穴ごとの正解回数・SM-2履歴も確定しないため、その問題は学習履歴上も未完了の状態へ戻ります。
- 結果画面には `問題 N周目 完了` を表示します。
- v2.4以前の履歴は、同じ問題に属する穴のレビュー履歴から問題の周回数を自動復元します。
- 問題文または解答内容を変更した問題だけは、古い問題周回を誤って引き継がないよう問題の周回数をリセットします。変更していない穴の学習履歴は従来どおり保持されます。

### 「今日の学習」の選定順

- 復習候補は、各穴の経過日数と設定間隔から `0.9^(経過日数÷間隔日数)` で推定した**保持率が低い問題**を優先します。期日当日は約90%として扱い、期日を過ぎるほど指数的に低下します。
- 推定保持率が同程度なら、直前に不正解だった問題、累計失敗回数が多い問題、期日が古い問題を先にします。
- それでも同条件なら、完了した問題周回が少ない問題を先にし、完全同点だけをランダムにします。
- 復習候補を日次上限・セッション長の範囲で確保した後、残り枠だけ未学習問題を補います。固定の混合比率は使いません。
- 選ばれた新規問題は復習問題の間へ均等に差し込みます。ただしセッションの1問目は必ず復習です。
- 回答途中でセッションを中断した回は、穴履歴・問題周回・日別集計のいずれにも反映しません。
- v2.6.0で回答途中の表示回数が保存されていた場合は、更新後の初回起動時に完了済みの問題周回数へ自動補正します。問題・穴の既存正解履歴は保持します。

**解答方式**:
- 各穴に答えを入力して自動判定します。複数穴は1個ずつ順番に回答します。
- 全ての対象穴を判定し、最後に「結果を見る」を押した時だけ、穴履歴・問題周回・日別学習数を一括保存します。

### 「新規を学ぶ」の対象

- 「新規を学ぶ」では、問題内の**すべての穴に学習履歴がない問題だけ**を出題します。
- 1回または2回正解した定着中問題は出題しません。
- 一部の穴だけを学習済みの問題、誤答履歴がある問題、復習期日待ちの問題も出題しません。
- 未学習問題の中では、従来どおり完了回数が少ない順、同数の場合はランダムに出題します。
- 定着中問題は、期日が来た場合だけ「今日の学習」の候補になります。

### 出題中に問題を編集した場合

- 学習画面の編集ボタンから問題を変更して保存すると、その問題は**現在の学習セッションから除外**されます。
- 保存直後に、変更後の同じ問題をもう一度表示することはありません。次の問題が残っていれば、その問題へ進みます。
- その問題がセッション最後の1問だった場合は、セッション完了画面へ進みます。
- 編集前に途中まで回答していても、「結果を見る」前であれば、穴の正解回数・SM-2履歴・問題周回数・日別学習数には反映しません。
- 問題そのものを削除する動作ではありません。次回以降に新しく開始するセッションでは、更新後の内容と学習状態に応じて通常どおり出題候補になります。
- 編集をキャンセルして学習画面へ戻った場合は、従来どおり同じ問題の回答を続けられます。

### 問題の管理はCSVで行う(基本)

問題の追加・編集・削除は、PCのExcel等でCSVを編集して行います。アプリ上では基本的に編集しません。

**基本フロー**:
1. PCのこのアプリで **設定 → 問題の管理(CSV) → ① CSVをエクスポート(id付き)** を押し、現在の問題をCSVで取得(初回でまだ問題が無ければスキップ可)
2. そのCSVをExcel等で開き、行の追加・編集・削除を行う
3. **設定 → ② CSVから同期する** で編集後のCSVを取り込む
4. 確認画面に「新規追加◯件 / 履歴リセット◯件 / 削除◯件」が出るので確認して実行

**CSVの列**:

| 列 | 必須/任意 | 説明 |
|---|---|---|
| `Q&A` | 必須 | 問題と解答を一体化した本文。空欄にしたい語を `【】` で囲む。**囲んだ中身がそのまま解答**になる。例: `【業績】や【事業活動】を【コンプライアンス】に優先させない` |
| `id` | 任意 | 問題の追跡用ID。アプリのエクスポートで自動付与。**編集時は残すこと**(消すと新規問題扱い) |
| `category` | 任意 | `common` / `solution` / `engineering`(日本語表記も可)。省略時は common |
| `tags` | 任意 | セミコロンかカンマ区切り |
| `source` | 任意 | 出典 |
| `year` | 任意 | 対象年度 |
| `importance` | 任意 | 1〜5。空欄は3 |
| `author` | 任意 | 作成者名 |

`Q&A` 列の書き方:

```
Q&A
【業績】や【事業活動】を【コンプライアンス】に優先させてはならない
基準価格は【10.82】円
```

- `【...】` で囲んだ語が空欄になり、囲んだ中身が解答になります
- 穴が複数あれば、出題時に自動で ①②③… と振られます
- 穴が1個でも複数でもOK
- 最小構成は `Q&A` 列だけでも動きます(カテゴリ等は省略可)
- 旧形式(`question`/`answer` の2列)も引き続き読み込めます

**同期の挙動(学習履歴の扱い)**:

| CSVでの操作 | アプリでの結果 | 学習履歴 |
|---|---|---|
| 行の `question`/`answer` を変更 | 内容更新 | **リセット(新規問題扱い)** |
| 行の `tags`/`importance` 等だけ変更 | メタ更新 | **保持** |
| 新しい行を追加(id空欄) | 新規問題が増える | まっさら |
| 行を削除 | アプリからも削除 | 痕跡は残り、復活で再開可能 |
| 変更なし | そのまま | 保持 |

問題文と解答の内容ハッシュで「内容が変わったか」を判定します。`id` 列が無い/空欄の行は、問題文が一致する既存問題に自動で紐付けて履歴を維持します(問題文を変えた場合は新規問題になります)。

**重要**: CSVインポートは「CSVの内容にアプリを完全一致させる」動作です。アプリにあってCSVに無い問題は削除されます。常に**全問題を含むCSV**を取り込んでください(部分的なCSVを入れると他が消えます)。

**社外秘の注意**: CSVには社外秘を含みうる問題が入ります。AirDropや社内ファイル共有など端末間の直接転送を使い、外部サービス経由を避けてください。

### ローカル出典データ

ローカル専用の `source-pack.local.json` には、出典として実際に使うPDFページのスクリーンショットとハイライト座標が入っています。元PDFをブラウザで毎回解析・描画しないため、回答後の表示は高速です。本文抜粋と文字マーカーはパックから除外し、画面にも表示しません。

- 問題の `id` を優先し、IDがない行は問題文＋解答の内容ハッシュで照合
- 添付CSVの641問すべてを照合
- 297枚のページ画像を問題間で共有し、641問すべてで該当ページ画像を表示
- 540問はPDF上の穴抜き解答位置を座標で特定し、ページ画像に黄色の枠を重ねて表示
- 画像上の位置を安全に特定できない場合は、誤った枠を出さず正しいページ画像だけを表示
- 新たに提供された `01.法人営業2026年度計画.pdf` の問題にもページ画像・ハイライトを付与
- 画面の `PDF p.N` はPDFファイル上の物理ページ番号。資料内の印刷ページ番号とは表紙・目次分ずれる場合あり

ページ画像はWebPへ軽量化し、同じPDFページを複数問題が参照しても端末には1枚だけ保存します。学習中は現在表示しているページだけをIndexedDBから読み込み、画像URLのメモリキャッシュも少数に制限しています。

旧 `source-index.local.json` も互換のため読み込めますが、ページ画像は表示されません。今回のPDFページ画像を表示するには、新しい `source-pack.local.json` を読み込んでください。

出典データは設定画面から削除できます。削除しても問題・学習履歴は残ります。全データ削除を実行した場合は、出典メタデータとページ画像の両方が削除されます。

**GitHubへ置いてよいもの:** `index.html`, `app.js`, `styles.css`, アイコン、README、`.gitignore` などのアプリ本体。

**GitHubへ置いてはいけないもの:** `source-pack.local.json`, `source-index.local.json`, `questions-*.csv`, `共通*.zip`, `ソリューション*.zip`, 元PDF、ページ画像、ローカル生成ツール一式。

### 複数人で同じ問題集を使う

代表者がCSVを管理し、各メンバーがそのCSVを「CSVから同期する」で取り込みます。学習履歴は端末ごとに独立するため、誰がどれだけ進めても他の人には影響しません。

### 試験日とペース管理

**設定 → 試験日** を入力すると「試験まで N 日」が表示されます。  
**統計**タブで、直近30日の「1日で勉強した問題数」と「穴あき正解率」の推移、現在の習得進捗、必要な1日あたりの消化量を確認できます。問題数は完了した問題を1回ごとに集計し、更新前の期間は既存履歴から日別・問題別に重複除去して復元します。

### 日別の穴あき正解率

- 正解率は、各日の **正解した穴数 ÷ 回答した穴数** で計算します。
- 直近30日を日別の棒グラフで表示し、今日・直近7日・直近30日の正解率と回答穴数も表示します。
- 直近7日・30日の数値は、その期間内の全回答穴を合算した加重正解率です。
- 全穴を回答して「結果を見る」まで完了した問題だけを集計します。回答途中で中断した問題は含めません。
- 「やっぱり正解だった」で訂正した穴は正解として集計します。
- 新しい保存領域は追加せず、既存の穴別履歴から計算するため、バックアップ・iCloud同期との互換性を維持します。

## トラブルシューティング

**Q: アップデート後に画面が古いままになる**  
A: ブラウザのキャッシュをクリアして再読み込みしてください。

**Q: 問題が消えた**  
A: 設定 → 「シード問題を再読込(マージ)」で初期問題のみ復元できます。ご自身で追加した問題が消えた場合、以前にエクスポートしたJSONから復元してください。

**Q: 出典が解答下に出ない**  
A: 設定 → ローカル出典データの状態を確認してください。「未読み込み」なら `source-pack.local.json` を読み込みます。問題文・解答を編集した問題は内容ハッシュが変わるため、出典パックの再作成が必要です。

**Q: 出典は出るがページ画像がない**  
A: 旧 `source-index.local.json` を読み込んでいる場合は文字だけが表示されます。設定から `source-pack.local.json` を読み込み直してください。元資料側でページを特定できない問題には画像を表示しません。

**Q: ページ画像は出るが黄色い枠がない**  
A: 穴抜き解答の位置を安全に特定できないページには、誤った枠を出さずページ画像だけを表示します。原文の文字抜粋・文字マーカーは仕様として表示しません。

**Q: 全てリセットしたい**  
A: 設定 → 「全データを削除」。ローカル出典索引も削除されます。

## プライバシー

- 問題・進捗・設定・ローカル出典パックは全てこの端末の `IndexedDB` にのみ保存されます
- PDFページ画像はBlobとして出典メタデータと分離保存され、表示中のページだけを読み込みます
- ローカル出典パックは通常バックアップとiCloud同期から意図的に除外されています
- 外部サーバーへの送信は一切ありません
- アプリ起動後は完全オフラインで動作します
- 分析・トラッキングなし
- 入力フォームは `autocomplete="off"` でブラウザ自動保存無効化

## 端末間の同期について（重要）

このアプリはサーバーを持たず、データは各端末の中（IndexedDB）にだけ保存されます。

- **問題データベースは自動同期されません。** PCとスマホは独立しています。CSVを書き出して相手に取り込む（「CSVから同期する」）ことで手動で揃えます。`id`列で問題を対応づけます。
- **学習履歴と日別学習数は勉強する端末（スマホ）の中だけ**にあり、CSVには含まれません。CSV経由では移動しません。全データバックアップ／iCloud同期ファイルには両方を含めます。
- 頻繁に両方で編集する場合は、**編集したらすぐCSVを書き出して、それを次の正本にする**運用にしてください（PC編集→スマホ取込／スマホ編集→CSV書き出し→PCで使用）。古いCSVを取り込むと新しい編集が上書きされます。

### 学習履歴は「穴の解答の中身」にひも付く

進捗は穴ごとに、しかも**穴の中の解答内容**で記録されます。そのため編集しても履歴は最大限保持されます：

| 編集 | 学習履歴 |
|---|---|
| 穴の位置を動かす | 保持（中身が同じなら追従） |
| 問題文（穴以外）を直す | 保持 |
| 穴を追加 | 追加分だけ新規、他は保持 |
| 穴を削除 | 削除分だけ消える、他は保持 |
| 穴の中の解答を変更 | その穴だけ新規、他は保持 |
